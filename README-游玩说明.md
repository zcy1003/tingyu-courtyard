# 欢迎来到听雨小镇

版本：0.3.0（2026-10-21）。第三人称街区漫游，支持自由切换天气与时辰。默认从细雨夜晚出发。

## 打开游戏

双击同目录的 **启动听雨小镇.cmd**，等“走进小镇”亮起后点击。游玩期间保留启动窗口，关闭窗口或按 Ctrl+C 停止本地服务器。

需要 Python 3 与支持 WebGL 2 的电脑浏览器；游戏运行时不联网下载资源，也不需要账号。可在项目目录运行：

```powershell
python scripts/play.py
```

默认入口是 `http://127.0.0.1:8001/`。端口被占用时可用 `python scripts/play.py --port 8002`。根目录的 `index.html` 是初版无人物的观景模型，新版通过上述启动器打开。

## 走走看看

| 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 相对镜头行走 |
| Shift + 行走 | 轻跑 |
| 鼠标左键或右键拖动 | 观察四周 |
| 鼠标滚轮 | 调整镜头远近 |
| H | 隐藏或显示界面，继续行走观景 |
| M / 右下角地图 | 查看街区与到访记录 |
| P | 拍照模式；调整视角并保存无界面的 PNG |
| T / 右上角“景” | 打开天气与时间面板 |
| Esc / 右上角菜单 | 暂停、帮助与三档画质 |
| R | 回到听雨小院 |
| 右上角“声” | 开关合成雨声、水声与檐下滴水 |

出生时面向听雨堂，可进入茶室；转身穿过月洞门就到青石雨巷。向东走过石桥，到竹影水街；再向南经过木桥，沿柳岸和茶铺返回。地图以白色箭头标出你的位置，七处地点会显示首次到访提示。西侧巷角和东北灯下巷口也是可到达的支路。

听雨堂、春和茶铺、一叶茶与竹里书屋可以进入；其他民居用于室外观赏。河道设有岸栏，远处没有可探索的大面积草地。到访记录保留在本次打开期间，刷新后重新开始。

## 天光与风雨

按 **T** 或点击右上角“景”，也可从暂停菜单或拍照模式打开设置。

时辰可选“清晨、白天、夕阳、夜晚”；天气可选“晴朗、多云、细雨、大雨”。两者可以任意组合，选择后画面平滑过渡。主光、天空、云、雾、灯笼、雨丝、地面干湿、倒影与环境声会一起变化。晴天不再下雨，地面积水数秒内逐渐收起；雨天恢复湿润反光。

勾选“自动昼夜流转”，约 8 分钟经过一昼夜。打开暂停、地图或天气面板时会停止计时，拍照模式仍可流转；若想固定拍照光线，请选择一个时辰，自动流转会随之关闭。按 T、Esc 或“返回取景”关闭面板，从拍照进入时会返回拍照模式。

设置会保存在当前浏览器中，刷新后仍使用你的选择；声音开关不会自动打开。不同端口或不同浏览器各自保存设置。

## 画面

默认“均衡”包含细线轮廓、接触阴影、克制的灯光柔辉、雨丝、湿地和河道倒影。“轻盈”降低像素密度、阴影和倒影更新成本；“细致”提高分辨率与阴影质量。运行吃力时，在暂停菜单切换“轻盈”。

这是按初版雨夜微缩景观重新整理的风格化三维游戏。保留人物与自由漫游，整张地图使用统一的雨夜色彩和材质。主要面向电脑键鼠，尚未加入手机摇杆、NPC 任务、战斗或存档。
