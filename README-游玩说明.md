# 欢迎来到听雨小镇

版本：0.1.0。电脑浏览器中的第三人称江南小镇漫游游戏。

画面更新：2026-10-21，新增人物与建筑细节、湿润青石、花草层次、接触阴影和动态水面倒影。

## 打开游戏

双击同目录的 **启动听雨小镇.cmd**。浏览器会打开游戏，等“走进小镇”按钮亮起后点击即可开始。游玩期间保留启动窗口；关掉窗口或按 Ctrl+C 可以停止本地服务器。

本机已经安装 Python 3。解压版本在其他电脑使用时也需要 Python 3 与支持 WebGL 2 的电脑浏览器。游戏本身不需要联网下载资源，不需要账号。

也可在项目目录执行：

```powershell
python scripts/play.py
```

默认入口是 `http://127.0.0.1:8001/`。端口被其他程序占用时，可使用 `python scripts/play.py --port 8002`。根目录的 `index.html` 是保留的原版雨夜小院，**新版游戏通过上述启动器打开**。

## 怎样走走看看

| 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 相对当前镜头行走 |
| Shift + 行走 | 轻跑 |
| 鼠标左键或右键拖动 | 看四周 |
| 鼠标滚轮 | 调整镜头远近 |
| M / 右下角地图 | 查看整座小镇及已到访的地点 |
| P | 拍照模式；可调整视角并保存没有游戏界面的 PNG 照片 |
| Esc / 右上角菜单 | 暂停、操作说明与画质设置 |
| R | 回到听雨小院 |
| 右上角“声” | 开启或关闭风、水与鸟鸣的合成环境声 |

人物最初面对听雨堂。可以先走进茶室，也可以转过身穿过背后的月洞门出院。沿青石巷走向树下广场，经过望溪石桥，到东岸竹里和临水亭；向南走过归云木桥，再沿西岸返回。东北小亭和西南花园也是可以到达的支路。

地图上的白色箭头表示你的位置和视角方向。七个主要地点在第一次接近时会显示到访提示。到访记录保留在本次打开的游戏中，刷新页面后重新开始。

## 画面与范围

“均衡”是默认画质。若运行吃力，在暂停菜单切换为“轻盈”；“细致”提高像素密度和阴影分辨率。镜头遇到墙、屋檐或柱子时会自动靠近人物，离开后恢复距离。

此版本完成自由行走、两岸完整环线、七处风景、可进入的茶室和三维环境。角色与建筑由程序化模型实现，按原型保留服装、青瓦、月洞门、竹柳与春日水景，几何和材质细节仍比概念图简化。其他民居主要用于室外观赏；河道和远山是景观边界。

当前主要面向电脑键鼠，尚未加入手机虚拟摇杆、NPC 任务、战斗或存档。
