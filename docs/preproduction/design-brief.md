# 听雨小镇 · 体验与美术规格

状态：编码前设计基线。数值是灰盒起点，须在实际场景中调整；不代表已实现或实测。

## 首版体验

一款电脑浏览器中的单人第三人称游览游戏。玩家从听雨小院出发，走入茶铺街巷、树下广场，穿过石桥，沿竹林和临水亭漫步，经木桥回到西岸。环境时间固定为春日雨后清晨，光照清新、温暖、通透。

首版包含：键鼠行走、可转动的跟随镜头、基本角色待机/步行动画、实体碰撞与台阶、完整游览环线、可进入的起点茶室、简洁进入/暂停提示、重置到安全出生点、适度水面和植被运动。

后续扩展项：移动端触控、NPC 和对话、任务、采集、战斗、背包、游泳、跳跃、昼夜天气切换、联网和存档。首版主要建筑以室外观赏为主，仅起点茶室要求可以进入。

实际原型呈现的是细腻的风格化 3D，人物比例接近约 6.5–7 头身。制作时以图片为准，不沿用早期提示词里的 5.5 头身。避免方块人、粗黑轮廓和过度塑料光泽。

角色背包固定在人物自身右侧髋部，背带由自身左肩跨向右髋。人物左右以解剖方向判定，不随画面左右翻转。图 5 为造型约束，最终运行时仍需真实三维模型与动画。

## 色彩和材质

以下为制作起始色，人工按参考图估计，尚未进行色卡采样或显示器校准：

| 用途 | 起始色 | 材质表现 |
| --- | --- | --- |
| 墙面 | `#E8DFCB` | 暖白灰泥，略有色差，局部苔藓，不泛黄发光 |
| 屋瓦 | `#647875` | 青灰色、轮廓清楚、中高粗糙度 |
| 木构 | `#8B653D` | 暖木色、轻微木纹，不统一涂成深褐色 |
| 石板 | `#A6A99C` | 浅灰暖绿、边缘磨损、局部湿润 |
| 水体 | `#5BAAA2` | 青绿、浅岸透色、轻微波纹与反光 |
| 叶片 | `#7E9850` / `#A8B868` | 深浅分层，保持空隙和透光感 |
| 灯笼 | `#CB7443` | 小面积暖橙红，不用过曝红光覆盖白天环境 |
| 上衣 | `#497C77` | 布料、低金属感；裤装接近米白 |

主要风格依靠形体、合理比例、光照和色彩建立。近景瓦檐、窗棂、石桥栏杆和水缸是重点细节；远景建筑逐步简化。石板反射只在小面积湿处出现。远山作为环境边界，避免被误读为可攀登区域。

渲染初始方案采用线性色彩计算与 sRGB 输出、单一主阳光、柔和环境光和轻雾。具体曝光、色调映射和环境强度在第一个场景中对照图 1/3 调校。先保证基础光照，再评估环境遮蔽等后处理。

## 操作与相机

| 动作 | 首版设计 |
| --- | --- |
| 行走 | WASD / 方向键，相对于相机水平朝向；斜向归一化 |
| 视角 | 鼠标左键或右键拖动旋转；按下时捕获指针，抬起/取消时释放状态 |
| 缩放 | 滚轮，在安全范围内缩放跟随距离 |
| 暂停 | Esc，暂停输入与模拟；帮助面板展示操作 |
| 复位 | R 或暂停面板中的“返回小院”，恢复安全位置与镜头 |
| 页面失焦 | 清空按键和拖拽状态，恢复焦点后不残留移动 |

默认不要求鼠标锁定。用拖拽观察降低首次进入门槛。镜头以人物胸背部为目标点，保持地平线稳定，朝向变化与距离恢复平滑。

- 世界单位 1 = 1 米；角色目标身高 1.65 米。
- 初始步速 2.0 米/秒，帧率无关。先把普通步行打磨好。
- 相机垂直视场角初值 50°，后距 4.2 米，目标高度 1.15 米，初始俯角约 16°。
- 户外缩放范围初设 2.0–6.0 米；遮挡时允许临时缩短至约 0.5 米，并淡出过近的角色局部。
- 在 16:9 主画面对照中，人物目标占画面高度约 25%–35%，以图 1/3 实际构图为准。
- 镜头避障需要按摄像机近裁面体积处理，不能只用一条射线判定。
- 室内镜头优先缩短和调整仰俯角，保持地面和出口可见；屋顶遮挡可对局部模型做透明处理。

## 美术验收

固定记录三处机位：图 1 风格的 C 广场/石桥、西北小院门内望茶室、D 石桥望向 E 亭。对比人物占比、天空与地面明度、建筑轮廓、河水色相、绿植密度和可行走空间。

生成图含有高密度细节与理想化光照。最终品质要在真实 3D 资产、实时光照和性能约束下迭代；二维原型不会自动成为可行走模型。第一轮灰盒验收与最终美术验收分别记录，灰盒角色不作为最终角色交付。
